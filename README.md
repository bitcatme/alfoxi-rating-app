# ALFOXI Crypto Rating Platform

A modern crypto token and wallet rating platform where users can vote on their favorite digital assets.

## Features

✅ **Guest Voting (Free)**
- 5 free ratings per guest
- No registration required
- Votes saved in browser storage

✅ **Premium Voting (Scalable Donation Model)**
- $1 = 5 more ratings
- Donate multiple times for more votes
- PayPal integration: kusanhearath@yahoo.com

✅ **Rating System**
- Real-time vote counting
- Live trending charts
- Token and wallet ratings
- Search and filter capabilities

✅ **Business Contact**
- Professional inquiry form
- Company address: Kraichgaustr 2, 76661 Philippsburg, Germany
- Support for partnerships and listings

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Hosting**: Vercel / Netlify (Free tier)
- **Payment**: PayPal integration
- **Storage**: Browser localStorage + Backend (optional)

## Getting Started

1. Clone the repository
2. Open `index.html` in a browser
3. Start voting on crypto assets!
