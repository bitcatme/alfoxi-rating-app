# Cryp Rat - Crypto Ratings Live

A modern crypto token and wallet rating platform where users can vote on their favorite digital assets.

## Features

✅ **Guest Voting (Free)**
- 1 free rating per guest
- No registration required
- Ratings saved in browser storage

✅ **Registered Voting**
- 5 free ratings for registered users
- Registration and ratings saved in the current browser only

✅ **Rating System**
- Vote counting
- Live trending charts
- Token and wallet ratings
- Search and filter capabilities

✅ **Donations**
- "Feed me cheese" PayPal donation button

✅ **Contact**
- Professional inquiry form
- Support for partnerships and listings

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Hosting**: Vercel / Netlify (Free tier)
- **Payment**: PayPal integration
- **Storage**: Browser localStorage + Backend (optional)

## Getting Started

1. Clone the repository
2. Open `index.html` in a browser
3. Start voting on crypto assets!
